MiniCat 隐私协议

更新日期：2026 年 11 月 26 日

一句话说明：MiniCat 是一款 100% 本地运行的开源桌面宠物应用，不收集、不存储、不上传任何个人身份信息、按键记录或鼠标轨迹，无广告、无第三方数据追踪。

1. 信息收集与使用

MiniCat 不会主动收集任何用户数据，也不接入任何第三方统计、分析或广告 SDK。

  • 键盘与鼠标事件：仅在您的设备内存中实时处理，用于驱动小猫敲键盘、移动鼠标和展示动画，事件离开内存即丢弃，绝不写入日志或发送至任何服务器。
  • 密码输入防偷窥：当系统焦点进入密码输入框（如 macOS 安全输入 / Windows 密码框）时，MiniCat 会在底层自动暂停按键转发并让猫咪闭眼，保护您的输入隐私。

2. 系统权限说明

  • 辅助功能 / 输入监控权限（macOS）：仅用于监听全局键鼠动作以驱动桌宠动画，以及在密码框场景下自动触发防偷窥闭眼。
  • 本地配置存储：外观皮肤、窗口位置、缩放比例等偏好设置仅保存在您本机用户目录中，随时可手动删除。

3. 网络请求说明

MiniCat 默认完全离线可用。仅在您主动点击「检查更新」或启用版本提醒时，才会向 GitHub Releases 发起一次只读请求以获取最新版本号，不包含任何设备标识或个人隐私信息。

4. 开源与联系我们

MiniCat 为 MIT 协议开源软件，全部代码公开可审计： github.com/xpfyg/minicat。 如对本隐私协议有任何疑问，欢迎在 GitHub Issues 中反馈或联系开发者 xpfyg。

Privacy Policy (English Summary)

MiniCat is an open-source desktop companion app that runs 100% locally on your device. We do not collect, store, sell, or transmit any personal data, keystrokes, mouse activity, or analytics. Global keyboard and mouse permissions (such as macOS Accessibility and Input Monitoring) are used solely in-memory to animate the pet and automatically pause input forwarding when a password field is focused. Preferences are stored locally on your machine, and optional update checks only query public GitHub Releases without sending personal identifiers.
