🛡️ Windows 提示「通常不会下载 .exe」怎么办？

本项目为免费开源软件，未购买商业 EV 代码签名证书，Edge 可能拦截新版本安装包。
Edge：鼠标移到下载条 → 点右侧 ··· → 「保留」→ 弹窗出现「删除」时，点旁边下箭头 ▾ → 「仍然保留」。
Chrome：按 Ctrl + J → 「保留危险文件」→ 「仍然保留」。
安装时蓝框：点「更多信息」→「仍要运行」。

🎮 游戏全屏 / 直播怎么显示？

单机与常规游戏：全屏优化或无边框窗口化下保持 Z 序置顶且不抢焦点，建议开启「锁定鼠标穿透」，按住 Alt 可临时解锁； 若游戏以管理员权限运行，右键托盘选择「以管理员身份重启」。
直播录屏：OBS 添加「窗口捕获 → MiniCat」叠加。
强内核反作弊网游：游玩前右键托盘开启「暂停监听并隐藏（游戏反作弊护航）」。
